### Express  访问前端页面

` express.static` 静态托管页面

```js
import express from 'express';
const app = express();
app.use(express.static('public'));

app.listen(2333, '127.0.0.1', () => {
    console.log('Server running');
})
```

> 默认`/`会返回`index.html`  返回其他文件需要访问详细路径

### 前端获取的数据传回  Express

通过`fetch/axios`发请求到后端

1. get 方式提交

```js
// 前端
const response = fetch('/search?handle=abc');
// 后端
app.get('/search',(req, res) =>{
    const handle = req.query.handle;
})
```

2. post 方式提交

```js
const res = await fetch('/submit', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ handle })
  });
```

### 前端数据处理（ JS 插入网页 ）

1. `innerHTML` 快速插入或更新 HTML 内容，会替换所有的子内容

2. `textContent` 插入纯文本内容，会替换所有子内容

3. `inserAdjacentHTML` 在元素的指定位置插入 HTML ，不会替换已有内容

4. `createElement + appendChild` 动态创建和添加 DOM 元素，适合复杂结构

   ```js
   const container = document.getElementById('container');
   
   // 创建新元素
   const heading = document.creatElement('p');
   heading.textContent = 'create heading';
   const par = document.creatElement('div');
   par.innerHTML = '<p>create paragraph</p>;
   
   // 将新元素添加到容器中
   container.appendChild(heading);
   heading.appendChild(par);
   ```

   > 页面结构

   ```html
   <div id="container">
       <p>
           create heading
           <div>create paragraph</div>
       </p>
   </div>
   ```
